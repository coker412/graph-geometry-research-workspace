# 研究核心

先写对象、量词、假设、定义、归一化及本轮目标和可证伪验收。核对图类型、权/测度/距离、曲率、拉普拉斯符号与空间、流时间及存在区间、Einstein/Ricci-flat 的含义，以及有限/连通/局部有限等假设。名称相似不是定理适用的依据。

默认探索：发散、选路线、深入推导、局部检查、诊断、修复或回退。初次研究或结构性改线时提出至少三个实质不同的方法族；后续沿 CURRENT_STATE 的具体缺口推进。普通代数错误立即修复。脆弱断言主动找反例；依赖未核验步骤的结果标 conditional/GAP，不能作为已证下游前提。

搜索承诺 affirmative-proof/counterexample/either 只决定搜索目标。假定存在肯定证明不构成证据，主问题反例不能隐瞒。文献状态未核实不声称新颖或开放。

来源逐条标 internal-offline/provided-source/web-source/mixed。offline 禁止互联网、连接器和未经题包允许的外部本地材料；外部记忆仅是待核查线索。connected 必须核对原文。mixed-isolated 在汇合前不互读，两支来源不能追溯改写。来源标签不是隔离措施或数学认证。

证据等级：conjecture 无证明；experimental 计算证据；partial-result 仅较弱/特殊情形；proof-draft 完整未独立核验的候选证明；agent-verified 独立审查通过；human-verified 研究者逐步接受；formalized 形式系统通过。每条结论保留假设、依赖、反例检查、直接证据与来源。认证触发时读 proof-audit 协议，冻结依赖分支。

CURRENT_STATE 是索引，证据冲突以原始材料为准。每轮交付具体中间结果、精确 gap、检验过的反例候选、排除路线、可复现实验或已核对的文献接口。文件数量、重命名、审计次数与状态整理不算数学推进。
