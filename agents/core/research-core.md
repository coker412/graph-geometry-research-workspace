# Research core

State objects, quantifiers, assumptions, definitions, normalization, round goal and falsifiable acceptance. Check applicable dimension, regularity, boundary, completeness/finiteness, metric/measure, curvature and operators. Only graph problems require graph type, weights and local finiteness. For new geometric objects consult agents/protocols/geometry-scope.md; cite existing conventions. Similar names do not establish theorem applicability.

Default: explore, select, derive, check, diagnose, repair or backtrack. For initial exploration or structural replanning, apply agents/protocols/explore.md and compare credible method families; otherwise pursue CURRENT_STATE's gap. Fix algebra errors promptly. Seek counterexamples to fragile claims. Mark unverified dependencies conditional/GAP, never proved premises.

Search contracts affirmative-proof/counterexample/either guide search only. Assuming a proof exists is not evidence; never hide a counterexample. Do not claim novelty/openness without checking literature status.

Before prolonged work on a target or substantial intermediate claim, apply agents/protocols/literature-check.md: reuse the known baseline, fill material gaps in authorized connected work, and test standard reductions before declaring a difference. Record the nearest result, usable input and remaining gap. Use covered results with attribution; reproduce only for an explicit verification or concrete extension objective, never count rediscovery as new progress. Read methods when useful, not only after failure. Explicit offline-first work retains its planned comparison boundary. Recheck records at task/route/batch decisions; unchanged coverage needs no new search. Respect modes, commitments and evidence levels.

Label each source internal-offline/provided-source/web-source/mixed. Offline excludes internet, connectors and external local material not allowed by the packet; external memory is only an unverified lead. Connected requires original sources. Mixed-isolated branches cannot read each other before integration or relabel origins afterward. Labels provide neither isolation nor certification.

Levels: conjecture (no proof), experimental (computation), partial-result (weaker/special case), proof-draft (complete candidate, not independently checked), agent-verified (independent review), human-verified (researcher stepwise acceptance), formalized (formal checks). Keep assumptions, dependencies, counterexample checks, direct evidence and sources per claim. Apply the certification boundary in root AGENTS.md through agents/protocols/proof-audit.md.

State is an index; original evidence controls conflicts. Deliver a concrete intermediate result, precise gap, tested counterexample candidate, eliminated route, reproducible experiment or checked literature connection. File counts, renaming, audit counts and state maintenance are not mathematical progress.
