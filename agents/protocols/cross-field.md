# Cross-field reformulation at a bottleneck

Use when a precise obstacle persists, especially after repeated failure of one mechanism, or when the researcher requests alternative formulations. Do not require a bottleneck for an explicit request or repeat this for routine algebra/every round. Support affirmative proofs, constructions, estimates, rigidity and counterexamples under the existing search contract. A hard problem is not presumed false. This is a search heuristic, not a theorem or a reason to change the project goal.

## Start from the obstruction to progress

Write the smallest missing statement with its objects, quantifiers, assumptions and constants. Identify what fails: existence, compactness, regularity, extension, an estimate, compatibility or reconstruction. Separate failure of this method from impossibility of the desired object.

Choose a few genuinely different representations suggested by this structure, not a checklist of disciplines. Reuse existing route records. Ask both:

- What sufficient structure would construct the object or prove the estimate?
- What necessary structure would its existence force, and can that structure be realized or ruled out?

## Build and test the mathematical connection

For each promising representation record:

1. **Dictionary:** geometric objects/data, operators, constraints and target quantities mapped to the new setting.
2. **Direction:** equivalence, sufficient condition for the original goal, necessary consequence, special case or analogy only. Write the actual implication; necessity alone proves no existence, and failure of a sufficient condition proves no impossibility.
3. **Transfer obligations:** lost information, extra hypotheses, dimension/regularity/boundary restrictions, constants and parameter dependence. State how a solution, estimate or contradiction returns to the original problem. Unproved connections remain conditional/GAP.
4. **First test:** derive one identity/estimate, construct a model or test a limiting case. Check scaling, degeneracy and quantifiers before broad literature search. A reformulation equally difficult for the same reason is not progress.

Possible entry points for geometry (questions to investigate, not automatic equivalences):

| Available structure / missing step | Possible language and tools | Transfer risk |
| --- | --- | --- |
| Distances, extension, coverings or finite approximations | Metric/discrete geometry: Lipschitz extension, nets, combinatorial decompositions | Distortion, uniform constants, reconstruction and smoothness |
| Energy, coercivity, weak limits or dual constraints | Functional analysis: variational methods, compactness, duality, operator estimates | Admissible-set closure, lower semicontinuity, attainment and regularity |
| Compatibility, gauge choice or local equations | PDE: elliptic/parabolic estimates, compensated compactness, conservation laws | Boundary conditions, derivative loss, global compatibility |
| Positive mass-preserving evolution or averaging | Probability: Markov semigroups, coupling, functional inequalities | Invariant measure, symmetry, completeness/nonexplosion, which norm is controlled |
| Symmetry, periods or global gluing | Algebra/topology: representations, cohomology, obstruction theory | Topological existence versus the required metric/analytic control |

An unfamiliar viewpoint is useful when it attacks the actual gap, even within PDE. Do not force an exotic connection or restrict the search to this table.

## Search, apply, return

Search by the transformed statement, operator or structural property, not only the original conjecture's name. Try target-field terminology and both existence/sufficiency and obstruction results as appropriate. Follow literature-check: inspect original theorem hypotheses and proof context, not semantic similarity. Offline rules remain binding; prepare queries and unverified leads without browsing. This protocol authorizes no extra agents, services, costs or network access.

Give each shortlisted representation a small substantive test, compare what it changes about the bottleneck, then focus on the strongest tool/route. Retain other promising alternatives; equal effort and simultaneous agents are not required. Actually attempt the tool's application. Deliver a derivation, usable result, precise remaining connection or documented mismatch; a list of fields/papers is insufficient. Keep sources and evidence levels. Complete candidates and high-risk dependencies still trigger proof-audit.

## Compact record

Use one project note with: **gap → dictionary/implication → candidate tool and exact source → application/check → effect on original goal and next test**. Record useful search queries, first source hit and the step that suggested them when available; distinguish observed search history from retrospective reconstruction. Do not invent why a model had an idea.

Keep only a pointer and the surviving gap/route in CURRENT_STATE, following existing writer rules. Update route/dependency files only for structural changes. If no representation yields a usable connection, record that fact and precise reopening conditions; do not repeat generic brainstorming or count this as mathematical progress. Preserve existing search commitments and stopping rules.
