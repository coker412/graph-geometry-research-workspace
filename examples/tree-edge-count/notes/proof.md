# Candidate proof

证据等级：`proof-draft`。

设 \(n=|V|\)。对 \(n\ge 1\) 归纳。

当 \(n=1\) 时，简单图没有环边。它没有边，因此 \(|E|=0=n-1\)。

设 \(n\ge 2\)，并假设结论对所有顶点数为 \(n-1\) 的树成立。因为 \(T\) 有限，\(T\)
中存在一条最长简单路径。设 \(v\) 是这条路径的一个端点。连通性说明 \(v\) 至少有一个
邻点。若 \(v\) 有一个不在路径上的邻点，则可以延长该路径。若 \(v\) 在路径上还有不同于
相邻路径顶点的邻点，则该邻边与路径的一段组成一个圈。这两种情况都不可能，所以
\(\deg(v)=1\)。

删除 \(v\) 及其唯一关联边，得到图 \(T'\)。删除顶点不会产生圈，所以 \(T'\) 无圈。任取
\(T'\) 中两个顶点 \(x,y\)。连通性给出 \(T\) 中连接它们的一条简单路径。叶子 \(v\) 不能
是这条路径的内部顶点，而路径的端点 \(x,y\) 都不是 \(v\)，所以该路径完全位于 \(T'\)。
因此 \(T'\) 连通。于是 \(T'\) 是有
\(n-1\) 个顶点的树。

由归纳假设，\(T'\) 有 \(n-2\) 条边。恢复被删除的唯一一条边后，

\[
|E|=(n-2)+1=n-1.
\]

归纳完成。
