这些样例取自 OpenAI 于 2026 年公开的数学稿件，用来展示具体输出和编辑取舍。写作例子提供英文稿和中文说明，学习例子展开一个局部计算；点击即可阅读，无需先安装 skill。

建议先看[六组精选改写](04-selected-revisions.md)：从两轮十六组试写中筛选，提供选定原段的完整中译、实际英文改写、中文对应和信息保留说明。它们主要展示压缩重复、明确指代与组织证明依赖；长度减少不单独作为质量判断。

## 如何比较

每页给出固定版本的原文链接和页码、任务提示、输出以及保留的数学内容。精选页使用选段的完整中文对译，避免用缩略概述作基线；英文原文通过 PDF 查看。这里没有故意写坏的“无 skill 基线”，也没有用文风分数宣称胜出。精选示例经过筛选，不能代表所有任务的平均效果。

摘要示例把结构改写和去防御性清理分开，后者只有一处删除，其他句子保持不变。因此可以检查具体差异，但不能据此估计该模块对所有论文的平均效果。这些是当前上下文中的编辑示例，不是匿名盲测或独立评审。

## 来源与数学状态

六份来源分别固定到 `openai/math` 的具体提交，篇名、版本、页码、原始 PDF 的 SHA-256 和短引见 [sources.json](sources.json)。已核对对应页面、选段上下文和局部公式，未重新审查来源稿件的完整主定理证明；英文改写保留的是来源稿件的主张，不构成新的正确性认证。

学习例子只复现一个局部微分恒等式，并增加教学计算。新增计算经过同一助手推导、自查和计算核验，尚未获得独立验证。它不证明来源稿件的全局构造或仿射极大方程结论。这里没有使用私人合作稿或未公开作者示范包。

来源仓库采用 Apache-2.0；保留其 [许可证](OPENAI-MATH-LICENSE)。短引和数学公式均注明来源；新写的讲解与编辑说明采用本仓库的 MIT 许可。这些示例由本项目制作，不代表 OpenAI 对改写或 skill 的认可。

## 重复检查

在本目录运行：

```bash
python3 check_examples.py
```

脚本检查本地链接，并以有理数精确核对 Hessian 的分块表达、平方配方和行列式恒等式的有限组输入，也检查丢失混合项、缺少严格凸性时的反例。计算检查不是一般情形的证明；一般推导写在学习页中。

这是局部 Markdown 展示，不是整篇论文学习 PDF。本次无需 LaTeX 环境。需要复现改写时，将每页任务提示和指定原文交给相应 skill；模型措辞可能不同，先比较列出的数学约束。
