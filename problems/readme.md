# Problems

本目录保存尚未解决的问题和猜想。普通问题可以继续按“一题一个 Markdown 文件”存放；需要机器长期轮转尝试的重要猜想统一放在：

```text
problems/important-conjectures/
```

只有文献线索、尚未提取成精确问题的材料先放在：

```text
problems/sources/
```

`sources/` 中的记录不是可运行题目。必须先核对原文、提取正式陈述、补全定义与假设，再由老师决定是否加入重要猜想队列。

已整理的问题集：

- [Grigor'yan 1999 问题集](grigoryan-1999-problem-set/README.md)：原文第 18 节的 28 个问题、主观难度排序和建议实验顺序；目前均未启动。

该队列只使用 GPT/Codex 作为日常研究 Agent。详细操作见 [important-conjectures/README.md](important-conjectures/README.md)。Rethlas 只是在老师逐次批准后使用的证明升级通道；队列不会自动调用 Rethlas，也不依赖 Danus 或 Claude Code。
