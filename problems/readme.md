# Problems

Store open problems and conjectures here. Ordinary problems can use one Markdown file each. Problems intended for persistent queue research belong in:

```text
problems/important-conjectures/
```

Literature leads that have not yet become precise problems may be kept in `problems/sources/`. Such notes are not runnable queue items. Check the original source, extract the formal statement, supply definitions and assumptions, and let the researcher decide whether to enqueue the problem.

Private problem collections and research-status notes are not part of this public framework. Add your own material after setup.

The queue uses Codex for ordinary research. See the [queue guide](important-conjectures/README.md). Rethlas is an optional escalation path requiring authorization for each run; the queue neither starts it automatically nor depends on Danus or Claude Code.
